# NSAG M15 — Isolation, Confinement, and Extreme Environment Governance

Retired standalone deployment of NSAG module M15, Isolation, Confinement, and Extreme Environment Governance (Space & Extreme Environments). The module's canonical page is https://nsag-site.vercel.app/m15.

**Live:** https://nsag-m15.vercel.app

## Status

This prototype has been retired. The deployment remains online as a record; it is not maintained and should not be treated as a current product.

## Repository contents

`index.html`, `vercel.json`, `og.png`, `favicon.svg`, `apple-touch-icon.png`

## Local development

Static site. No build step — open `index.html`, or serve the directory with any static file server.

## Deployment

Deployed on Vercel from `main`. Every push to `main` triggers a production build.
